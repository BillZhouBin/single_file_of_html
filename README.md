# 单文件小游戏合集 · Single-File HTML Games

> 一个**零构建、零依赖**的纯前端小游戏集合。每个游戏都是一个自包含的 `.html` 文件，双击即可在浏览器里玩——没有打包、没有本地服务器、没有 npm install。
>
> 设计理念：受限调色板 + 像素精灵 + 统一 UI 语言（详见各游戏的 `*-design-system.md`）。

---

## 怎么玩 / 怎么运行

1. 进入某个游戏的文件夹（如 `plane-game/`）。
2. 直接双击其中的 `*.game.html`（或拖进浏览器）。
3. 无需任何环境准备。**注意保持联网**——像素字体走 Google Fonts CDN，离线时会自动回退到 `monospace`，不影响游玩。

> 所有游戏均支持 **键盘 + 触摸双输入**，竖屏优先（9:16），桌面与手机都能玩。

## 像素飞机大战 · 玩法

- **目标**：操控战机击落敌机、躲避弹幕，撑过波次并在 45s 后挑战 Boss（三阶段 + 蓄力激光）。生命耗尽即结束，分数越高越好。
- **操作**
  - 桌面：方向键 / `WASD` 移动，`P` / `Esc` 暂停，`M` 静音，**自动开火**
  - 移动端：手指拖动战机（战机跟随指下偏移），自动开火；右上角暂停按钮
- **机制**：击杀累积 `combo` 触发分数倍率（最高 ×2.0）；Boss 按血量分 P1/P2/P3 阶段，弹幕逐级加密，P3 插入激光（蓄力期有闪烁竖线 + Boss 眼珠发光预警，可横向闪避）。
- **音效**：Web Audio 程序化合成（8-bit 声纹，零外部资源）——射击 / 爆炸 / 受击 / Boss 激光 / 连击音高随 combo 递增；BGM 为 128BPM 琶音循环（Am-F-C-G），`M` 键静音（含 BGM）。
- **持久化**：最高分存 `localStorage`，结束界面展示。
- **文件**
  - `plane-war-game.html` — 可玩原型（Canvas 像素渲染 + DOM UI 覆盖层）
  - `plane-war-design-system.md` — 完整 UI 设计系统（调色板 / 字体 / 组件 / 精灵规范 / 动效 / 可访问性）

## 热气球大冒险 · 玩法

- **目标**：操控固定在屏幕下方、只能左右移动的热气球，躲开不断下落的钢灰栅栏、收集宝石得分，活得越久、分数越高，后期下落越快。
- **操作**
  - 桌面：方向键 / `A`·`D` 左右移动（带惯性 + 软回弹），`P` / `Esc` 暂停
  - 移动端：手指拖动 → 热气球横向跟随指下位置；右上角暂停按钮
- **机制**
  - 热气球**起初黑白**；吃到**彩色闪电方块**后染上该方块颜色并进入**无敌**（约 4s，可穿过栅栏），无敌结束回到黑白。
  - 栅栏每行仅一个、长度 ≤ 半屏，必留可通过的空隙；**擦边险胜 +5**（纵向重叠但水平缝隙 < 10px）。
  - 空隙中随机生成**宝石**（计分，金宝石 +20、其余 +10）与**道具**：护盾（无敌 5s）/ 缓降（下落 ×0.5）/ 吸铁（宝石吸附）/ 双倍（计分 ×2）。
  - 难度由分数驱动（200 分/级）：下落速度 `60 + level*12`、生成间隔随等级收紧；闪电概率随等级升、道具概率随等级降。HUD 顶部有 `LV + 进度条` 实时显示。
  - 视觉反馈：吃宝石/闪电/道具粒子爆发 + 飘字、染色全屏闪光、气球移动倾斜 + 拖尾气流、远山远云视差背景。
- **持久化**：最高分存 `localStorage`，结束界面展示。
- **文件**
  - `hot-air-balloon-game.html` — 可玩原型（Canvas 像素渲染 + DOM UI 覆盖层）
  - `hot-air-balloon-design-system.md` — 完整 UI 设计系统（去色世界美学 / 染色机制 / 精灵规范 / 可访问性）

## 新增一个游戏（扩展约定）

本合集刻意保持"低门槛、强一致"。新增游戏请遵循以下结构：

```
single_file_of_html/
├── README.md            ← 本索引（记得把新游戏加进「游戏索引」表）
├── sprite-rules.md      ← 共享：跨游戏通用像素精灵选型规则
└── <game-id>/           ← 文件夹名用 kebab-case，如 snake / tetris / match-3
    ├── <game-id>-game.html        ← 必含：单文件可玩原型（HTML+CSS+JS 一体）
    ├── <game-id>-design-system.md ← 必含：该游戏的 UI 设计系统文档
    └── （可选）<game-id>-notes.md ← 其他补充说明
```

**硬性约定**
1. **单文件**：游戏本体必须是单个 `.html`，CSS 写在 `<style>`、JS 写在 `<script>`，零本地资源依赖（精灵用代码矩阵绘制，选型规则见根目录 `sprite-rules.md`）。
2. **双输入**：键盘 + 触摸都要可玩；核心操作两端等价。
3. **竖屏优先** 9:16，但桌面也要能正常玩。
4. **设计系统先行**：动手前先定调色板 / 字体 / 间距 tokens，再写界面（文档与实现对齐）。
5. **可访问性基线**：文本对比 ≥ 4.5:1、键盘完整可玩、尊重 `prefers-reduced-motion`。

**完成一个游戏后**：把它的条目补进顶部「游戏索引」表（名称 / 文件夹 / 类型 / 状态 / 一句话说明），保持索引即最新。
