# 零食大冒险 · UI 设计系统

> 参考来源：用户提供的 18 张游戏内截图（`~/Desktop/ref_img/零食大冒险/`）——微信小游戏「9月零食金币狂飙赛」。
> 设计目标：把这款高饱和扁平风的三车道零食跑酷，复刻成**零外部资源、单文件 HTML** 可玩的版本。
> 与同合集 `rabbit-racing/`（录像复刻版）的区别：本文档对应的版本以**静态截图逐像素测量**为准，几何参数由最小二乘拟合得出，而非逐帧差分。

---

## 1. 视觉定位

- **风格**：高饱和、扁平、卡通、甜品世界（"零食"主题贯穿场景与道具）
- **情绪**：轻快、刺激、节日促销感（彩旗、缎带标题、奖励券）
- **表现手法**：Canvas 2D **全程序化矢量绘制**，无位图、无字体文件、无网络请求
- **视角**：竖屏固定三车道后视，路面自消失点向下滚动
- **关键识别特征**：**白面 + 红描边 + 亮黄填充**的高对比卡通描边语言（角色、图标、按钮共用）

## 2. 色彩系统

| `shoulder` | `#CFD2E0` | 路肩 / 路缘 |

**角色专用色**（参考图实测）：
- 头部 `#FFFFFF`，描边 `#D8352E`（红）
- 眼睛 `#A9E2F6`（浅蓝叶片状）
- 连体衣 `#FFC02E`（亮黄），领口 `#D8352E`
- 轮胎 `#1A1A1A`

**对比度**：深色路面上使用白字 + 深色投影（`uiShadow`），实测对比度 ≥ 7:1；亮色面板上使用深色描边文字，满足 WCAG AA。

  `"Yuanti SC", "HanziPen SC", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", -apple-system, sans-serif`

| 场景 | 处理 |
|------|------|
| 页面标题（缎带） | 大字号 + 白色填充 + 红色粗描边 + 投影 |

| 说明与规则正文 | 中字号、深色文字置于浅色卡片 |

## 4. 布局与比例（实测标定）

**逻辑画布 `640 × 1287`**（参考图内容区尺寸，非 9:16）。画布按 `contain` 等比缩放居中（`s = min(vw/W, vh/H)`），桌面与手机均**不裁切**，超出的方向留黑边。

### 4.1 几何标定表

对 `key_005.jpg` 逐行/逐列扫描后做**最小二乘拟合**（内容坐标系 = 全图 y − 113）：

| 量 | 公式 / 值 | 拟合残差 |
|---|---|---|
| 路面半宽 | `halfW(y) = 0.5875 × (y − 296)` | < 2px（10 行采样） |
| 车道分隔线 | `div(y) = 0.1725 × (y − 285)` | < 2px（6 行采样） |
| 路面中心线 | `ROAD_CX = 319` | 实测 311~319.5 |
| 消失点 | `Y_VP = 296` | — |
| 草地（地平线）上沿 | `GRASS_TOP = 415` | — |
| 车道中心 | `x = 319 ± 218` 屏幕像素 | 实测 3 帧角色中心 |
| 透视投影 | `y = 296 + 2286 / z`，玩家位于 `z = 3` | → 玩家 `y = 1058` |
| 角色包围盒 | `190 × 260`（顶点 `y=790`、着地 `y=1050`、最大宽 185） | ±10px |

对应的世界单位常量：

```js
ROAD_CX = 319        ROAD_K = 0.5875      Y_VP = 296
C_Z = 2286           Z_P = 3              PXS = 100
LANE_WU = 2.18       // 单车道中心间距（世界单位）
DIVIDER_WU = 1.333   // 车道分割线相对中心的世界偏移
PLAYER_Y = 1058      // 角色轮胎着地 y
Z_FAR = 18.5         Z_NEAR = 2.28   // 生成 / 回收深度
```

> 改动上表即可整体缩放场景；投影函数为 `pX/gY/halfW/sZ/laneX`。

### 4.2 屏幕分区

- **顶部 HUD**：左「分数」+ 大号数字；左上圆形计时器；右上「暂停」+「喇叭」
- **中部**：跑酷主体（三车道 + 两侧草地与甜品装饰）
- **底部控制**：左右两个半透明深色圆形按钮 + 白色粗箭头

## 5. 游戏元素规范

### 5.1 玩家角色（白兔赛车手）
- 白色**双峰圆头**（宽 190）+ 浅蓝叶片眼 `#A9E2F6` + 红色粗描边 `#D8352E`
- 黄色拉链连体衣 `#FFC02E` + 红领口；黑色轮（轮距 ±83、轮胎宽 70）
- 整体包围盒 `190 × 260`，着地 `y = 1058`；换道时整体倾斜 `±0.075 rad`

### 5.2 金币
- 四层同心圆（高光/主体/边/暗部），带内嵌符号
- 轻微左右摆动（wobble）增加活泼感
- 拾取 +20 分 · 粒子爆发 + `+20` 飘字

### 5.3 雪糕筒路障（cone）
- 红锥体 + 白色环带 + 深灰底座
- 碰撞**立即结算**（`overReason = 'crash'`）

### 5.4 油桶道具（boost）
- 浅蓝罐体 + 深蓝暗部 + 灰盖
- 拾取进入 **3 秒加速**、分数 **×2**（参考图规则页原文：「3S 内分数翻倍」）
- 加速期角色带光环特效

### 5.5 场景
- 天空纯色 + 三层蓝色远山剪影 + 白云缓慢横移
- 草地纯色 + 树冠三层明暗
- 路面**纯色**（刻意不加渐变与噪点，与参考图一致）+ 白色虚线三车道 + 两侧路缘线
- 远端一团淡青白柔光（`fog`），制造纵深
- 路边大量**甜品造型装饰**（蛋糕卷 / 马卡龙 / 甜甜圈 / 冰淇淋 / 糖果 / `HXL` 木牌）

## 6. UI 组件

### 6.1 开始页（START）
彩旗 + 缎带标题「零食大冒险」+「每日赢 88元 零食金」横幅 + 奖品池卡片 + 图标列 + `HXL` 木牌 + 「点击参与」按钮。

### 6.2 规则页 / 教程页（RULES / TUTOR）
浅色卡片承载规则正文，配图标化示意；返回按钮位于固定位置。

### 6.3 倒计时（COUNT）
全屏大号数字 **3 → 2 → 1**（总时长 3.6s），伴随 tick 音与 go 音。

### 6.4 HUD（PLAY）
- 左：圆形计时器（60s 倒数）
- 中上：分数大数字
- 右上：暂停按钮 + 喇叭按钮（静音切换）

### 6.5 暂停（PAUSE）
半透明遮罩 + 「继续游戏」/「重新开始」双按钮。

### 6.6 结算（OVER / RESULT）
本局分数 → 结算卡（分数 / 最高分 / 排名 / 奖励档位）→ 可返回排行榜或重开。

**奖励档位**（参考图仅见「1860 分 → 4 元券」，其余为推测）：

| 分数 | 奖励 |
|---|---|
| ≥ 1800 | 4 元券游戏 |
| ≥ 1200 | 2 元券游戏 |
| ≥ 600 | 1 元券游戏 |
| < 600 | 参与奖 · 再来一局 |

**排名推算**：`rank = max(1, round(4000 − 1.28 × score))`

### 6.7 排行榜（RANK）/ 我的奖品（PRIZE）
列表式浅色卡片；除参考图明确出现的单条数据外，其余为模拟数据。

## 7. 状态机

```
LOAD → START ⇄ RULES / TUTOR / RANK / PRIZE
         ↓
      COUNT ──(3.6s)──→ PLAY ⇄ PAUSE
                          ↓
                        OVER → RESULT → START
```

## 8. 动效与反馈

| 事件 | 反馈 |
|---|---|
| 换道 | 0.16s 补间 + `±0.075 rad` 倾斜 + 短促点击音 |
| 吃到金币 | 金色粒子爆发 + `+20` 飘字 + 双音上行 |
| 拾取油桶 | 加速光环 + 色调闪光 + `sfx.boost` |
| 撞击路障 | 屏幕抖动（`G.shake`）+ 红色闪光 + 锯齿波下滑音 |
| 倒计时 | 每秒 tick 音；归零 go 音 |
| 屏幕闪光 | `G.flash` 随时间线性衰减（×4/s） |

## 9. 音效设计

Web Audio API **程序化合成**，零外部音频文件。优先复用 `shared.js` 的全局 `AudioContext` 单例（`SharedGame.Audio`），离线时降级为本地实现。

| 音效 | 合成方式 |
|---|---|
| `coin` | 三角波 1250→1700Hz + 正弦 1900→2300Hz 叠置 |
| `boost` | 方波两段上行 560→900→1350Hz |
| `crash` | 锯齿波 260→50Hz + 方波 95→38Hz |
| `click` | 正弦 780→1020Hz 短促 |
| `over` | 正弦双音下行 540→400 / 380→220Hz |
| `tick` | 正弦 880Hz 定频 |
| `go` | 正弦 1180→1560Hz |

> 参考图为静帧，**完全无法提取音频**，全部音色风格属合理推演。

## 10. 可访问性

- 键盘完整可玩：`←`/`→`、`A`/`D` 换道 · `Enter`/`空格` 确认与推进 · `Esc` 暂停恢复 · `M` 静音
- 触摸等价：点屏幕左/右半区换道、横向滑动（> 46px）换道、底部左/右大按钮
- 逻辑画布 `contain` 缩放，任意视口**不裁切**
- 深色路面上文字使用高对比投影，对比度 ≥ 7:1
- 触摸目标：底部圆形按钮直径 ≥ 100 逻辑像素
- 音频首次触摸自动解锁（`pointerdown` 一次性初始化），不阻塞开始流程
