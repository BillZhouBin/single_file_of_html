## 一、美学方向（Design Direction）

**复古街机 × 现代精致（Retro Arcade, Refined）**

飞机大战是强情绪、快节奏的街机品类。为避免"AI 网红配色"（青+深蓝发光套件），本设计采用**受限调色板**——这是像素艺术的本质约束，也天然形成强品牌识别：

- **深空蓝紫星空**作为背景分层（非纯黑，制造纵深），而非千篇一律的纯黑底。
- **珊瑚橙玩家战机**作为唯一主色记忆点，与所有敌人形成暖/冷对立。
- **品红 / 青绿 / 紫**三种敌机做难度分层，而非随机换色。
- 硬边像素、扫描线、指数缓动——克制但精准的"现代复古"质感。

**差异化记忆点**：珊瑚橙战机 + 金黄弹道 + 橙红爆裂粒子，构成一套"暖色 protagonist / 冷色 antagonist"的对比语言。

```css
  --bg-deep:   #161235;  /* 星空底层 */

  --boom-2: #ffd23f;  /* 爆炸核心 */
  --boom-3: #fff1c2;  /* 爆炸高光 */

```

**对比度校验（WCAG AA）**：`--text #f4ecff` on `--bg-void #0d0b1f` ≈ **15.8:1**（远超 4.5:1）；`--ui-accent #ffd23f` on 深底 ≈ **11:1**；`--player #ff6b5e` 作为图形元素不承载文本，符合非文本对比 3:1。

### 2.2 字体系统

```css
--font-display: 'Press Start 2P', 'Courier New', monospace;  /* 标题 / 分数 / 按钮 — 像素展示体 */
--font-mono:    'VT323', 'Courier New', monospace;           /* 正文 / 说明 — 高可读像素等宽 */
```

| 角色 | 字号（逻辑 px） | 行高 | 字重 | 用途 |
|------|----------|------|------|------|
| 巨型标题 | 14（展示体） | 1.4 | 400 | LOGO / GAME OVER |
| 分数数字 | 16（等宽） | 1 | 400 | HUD 实时分数 |
| 按钮 | 10（展示体） | 1 | 400 | 主操作 |
| 正文/说明 | 16（等宽） | 1.2 | 400 | 说明、提示 |

> 像素字体在小字号易糊，故正文改用 **VT323**（高可读像素等宽体），展示体仅用于标题/分数/按钮。Google Fonts 离线回退到 `monospace`。

### 2.3 间距系统（8px 网格，像素对齐）

```
--space-1: 4px   --space-2: 8px   --space-3: 12px
--space-4: 16px  --space-6: 24px  --space-8: 32px  --space-12: 48px
```
所有组件内边距/间距取 4 的倍数，保证 canvas 低分辨率下像素对齐、无亚像素模糊。

### 2.4 动效规范

- **缓动**：状态切换用 `cubic-bezier(0.16, 1, 0.3, 1)`（ease-out-expo），禁用回弹/弹性（避免廉价感）。
- **屏幕震动**：受击时 `translate` 抖动，幅度 2–6px，衰减 200ms。
- **无敌闪烁**：碰撞后 1.2s 玩家 60ms 周期透明度闪烁。
- **爆炸**：12–18 个方块粒子，初速随机，重力衰减，0.4–0.7s 消失。
- **尊重 `prefers-reduced-motion`**：关闭震动与扫描线闪烁，保留核心反馈。

## 三、组件库（UI Components）

> 所有界面用 DOM 覆盖在 Canvas 之上，非 Canvas 内绘制——保证文本清晰与可访问性。风格统一：像素描边 + 半透明面板 + 展示体标题。

### 3.1 主菜单（Main Menu）
- 居中面板 `--panel`，`--border` 2px 像素描边，`box-shadow` 模拟右下硬阴影。
- LOGO：展示体巨型标题，珊瑚橙填充 + 冰蓝描边。
- 主按钮「开始游戏」`--ui-accent` 底、`--bg-void` 字。
- 底部一行 VT323 提示：「← → / 拖动 移动 · 自动开火 · P 暂停」（即原「操作说明」内容，以**内联提示**呈现，未另设独立按钮）。

### 3.2 HUD（游戏内抬头显示）
- 顶部左右分布，**不遮挡战场中心**。
- 左：分数（`SCORE 000000` 等宽，零填充 6 位）。
- 中：波次/关卡（`WAVE 1`）。
- 右：生命（3 架迷你战机图标，失活置灰 `--text-dim`）。
- 连击：连续击杀在 1.2s 窗口内累计 `combo`，触发分数倍率（最高 x2.0），中央显示 `COMBO x?.?` 提示（combo≤1 时隐藏）。
- 顶部细扫描线渐变，强化街机感。

### 3.3 暂停（Pause）
- 半透明 `--bg-void` 遮罩（alpha 0.7）+ 居中面板。
- 「已暂停」+「继续 / 重新开始 / 退出」。
- 触发：桌面 `P` / `Esc`；移动端点击暂停按钮。

### 3.4 游戏结束（Game Over）
- 展示体「GAME OVER」`--ui-danger`。
- 本局分数 + 最高分（localStorage 持久化）。
- 「再来一局」主按钮 +「返回菜单」。
- 失败瞬间触发一次强屏幕震动 + 红闪。

### 3.5 按钮（Button）规范
```
.btn            --font-display 13px，padding 16px 28px
.btn--primary   bg --ui-accent，文字 --bg-void
.btn--ghost     transparent，1px --border 描边，文字 --text
hover           translateY(-2px) + 硬阴影；focus-visible 2px --cockpit 描边
active          translateY(0)
```

## 四、像素精灵规范（Sprite Spec）

> 渲染方式：Canvas 逻辑分辨率 **240×400**，CSS `image-rendering: pixelated` 放大；所有精灵以字符矩阵定义，每字符映射调色板索引，`.`=透明。精灵采用**手绘精细矩阵**，`SPRITE_SCALE=1`（1:1 像素渲染，无整数放大糊化）；细节（座舱/机翼高光/翼尖/引擎尾焰/深色描边）直接画进矩阵，而非靠放大凑尺寸。

### 4.3 弹药 / 爆炸 / 背景
- **玩家子弹**：3×8 竖直条 `--bullet`，每帧上移。
- **敌弹**：3×3 方块 `--bullet-enemy`（含 Boss 弹幕，支持斜向飞行，带 `vx`/`vy` 速度向量）。
- **爆炸粒子**：3×3 方块，随机取 `--boom-1/2/3`，带速度向量。
- **星空背景**：3 层视差星点（密度 0.6/0.3/0.1），向下滚动速度递增，颜色 `--text-dim` / `--border` / `--bg-glow`。

### 4.4 Boss（预渲染大精灵，48×34）
- **为何不走手敲矩阵**：按 `sprite-rules.md` 红线，Boss 属「大尺寸高细节」元素，手敲 48×34 矩阵极易出错且不可维护 → 改用**预渲染（bake）**：`buildBoss()` 程序化生成字符矩阵，`bakeSprite()` 一次性把矩阵画到离屏 `<canvas>`，之后每帧 `ctx.drawImage` 贴图（GPU 加速，近乎零成本），彻底解除逐帧 `fillRect` 的性能上限。
- **造型（v2 增强）**：宽舰体 + 圆角 + 深色描边、顶部天线、顶部金属高光条、中线装甲脊、中央**发光核心**（`e` 外壳 + `E` 金环 + `w` 白热 + `c` 冰蓝瞳，渲染层叠加脉动辉光）、两侧炮塔 + 朝下炮口、底部双推进器（增强 `G` 外焰 + `O` 芯 + `w` 高光）；调色板 `PAL_BOSS`（d/m/M/e/E/c/G/O/w）。
- **出现节奏**：`bossNextAt` 默认 45s 触发首只（比原型初版 55s 提前，减少空窗）；击杀后 `bossStage++` 并重置 `bossNextAt = elapsed + 50`。每阶段 HP = `40 + bossStage*20`。
- **行为（三阶段，按血量比例切换）**：入场下滑至 y≈26 → 正弦扫荡（x 左右、y 轻微浮动，阶段越高扫荡越快）。阶段阈值 `ratio = hp/maxHp`：① **P1（>66%）** 基础弹幕，每 1.7/1.4s 交替 扇形 5 发 / 瞄准 3 发；② **P2（33%–66%）** 弹幕加密，每 1.2/1.0s 交替 扇形 7 发 / 瞄准 3 发；③ **P3（≤33%）** 每 2 轮弹幕后插入一次**激光**（见下），其余时间维持基础弹幕。
- **血条**：Canvas 顶部居中绘制，填充色随阶段变化（P1 `#ff4d6d` / P2 `#ff7a3d` / P3 `#ff2d4d`），上方 `VT323` 标注「BOSS」或「BOSS · P2/P3」；Boss 战期间 HUD 波次位显示「BOSS」、暂停常规刷怪。
- **帧动画（Boss）**：推进器火焰 2 帧循环（`buildBoss(phase)` bake 双帧存入 `boss.frames`，`bFrameIdx`，0.16s）——帧 0 标准推进器（y29–32），帧 1 火焰延长（y29–33）且朝下炮口 `d`→`w` 白热。中央核心脉动辉光（`lighter` 叠加，见渲染层）保留，与推进器帧叠加营造引擎轰鸣感。

### 4.4.1 Boss 激光（P3 专属）
- **状态机**（每帧驱动）：`charge`（1.2s 蓄力，屏幕闪烁红色预警竖线 + 落点黄标，锁定玩家当前 x；**同时 Boss 中央眼珠红光脉冲发光**，作为更直观的蓄力提示）→ `fire`（0.9s 发射，18px 宽光束（比初版 12px 更宽）、起点上移使火束更长，外红内白芯；玩家处于光束 x 区间且无敌帧已过则受击）→ `cool`（0.6s 冷却）→ `idle`。
- **公平性**：激光在 `charge` 阶段锁定目标 x 并给出明确预警（闪烁竖线 + 眼珠发光），玩家有充足时间横向闪避；发射期间无敌帧防止连击秒杀。碰撞判定宽度（±9px）与渲染火束（18px）严格对齐。
- **节奏**：仅在 P3 触发，每 2 轮普通弹幕插入一次（比初版每 3 轮更频繁，复合压力更强），与扇形/瞄准弹幕交替，形成「弹幕压制 + 定点激光」的复合压力。
- **击杀**：10 连爆 + 清屏敌弹 + 屏幕强震，`score += 2000 * bossStage`。

## 五、响应式与平台

- **竖屏优先**（9:16），适配手机与桌面。
- `game-shell` 高度 `min(100vh, 100vw * 400/240)`，`aspect-ratio: 240/400` 居中。
- **输入双通道**：
  - 桌面：方向键 / `WASD` 移动，`P`/`Esc` 暂停，`M` 静音开关，**自动开火**。
  - 移动：手指拖动战机（pointer 事件，战机跟随指下偏移），自动开火；右上角暂停按钮。
- 不做"移动端隐藏功能"——所有核心操作在两端等价可用。

## 六、可访问性（WCAG AA）

- 文本对比 ≥ 4.5:1（已校验，最高 15.8:1）。
- 键盘完整可玩（移动/暂停/重开无需鼠标）。
- `prefers-reduced-motion` 降级动效。
- 触控目标 ≥ 44px（按钮与暂停键）。
- 分数/生命用文字+图标双通道，不依赖纯颜色传达状态。
- 音效仅为视觉事件的**增强反馈**（非关键信息），并有 `M` 键全局静音开关，兼顾听觉障碍与安静环境。

## 七、实现备注（Developer Handoff）

1. Canvas 固定 `width=240 height=400`（属性像素），CSS 放大 + `image-rendering: pixelated`。
2. 游戏循环用 `requestAnimationFrame` + 可变时间步长（`dt` 钳制上限 0.05s），避免卡顿或后台切换造成的巨大时间跳变；逻辑与渲染在同帧内顺序执行。
3. UI 层为独立 DOM 覆盖，`pointer-events` 仅在菜单/按钮上启用，避免遮挡触控移动。
4. 最高分 `localStorage('planeWar.best')`，失败态读取展示。
5. 精灵矩阵存为常量数组，`drawSprite(matrix, palette, x, y)` 统一渲染。
6. Boss 走预渲染路线：`buildBoss()` 生成矩阵 + `bakeSprite()` 离屏 canvas 一次性 bake，每帧 `drawImage` 贴图；玩家尾焰 `FLAME_FRAMES` 3 帧循环由 `drawPlayer()` 组合渲染。
7. 音效走 **Web Audio 程序化合成**（OscillatorNode + GainNode 包络 + 噪声爆音），零外部音频文件，保持单文件离线可用；AudioContext **懒初始化**、在首次用户交互（任一按钮点击 / `M` 键）时激活以符合浏览器自动播放策略；`shoot` 音 70ms 节流防高频堆叠；`M` 键切换 `sfxOn` 全局静音。

## 八、音效设计（SFX 声纹）

### 8.1 设计原则

- **8-bit 像素声纹**：以方波（square）为主音色，锯齿波（sawtooth）承担厚重/威胁感音效，噪声爆音（noise burst + 低通）承担爆炸质感——与视觉的像素美学同构。
- **短促优先**：单发音效 ≤ 0.35s，不抢节奏；Boss 出场/激光/死亡等大事件 ≤ 1.1s。
- **可辨性**：玩家方（射击/命中）走高音区，敌方威胁（受击/激光）走低音区+扫频，方向一听即辨。
- **性能**：全部实时合成，零解码/零文件体积；`shoot` 节流防堆叠，AudioContext 单实例。

### 8.2 音效清单

| 事件 | 触发点 | 波形 | 频率扫动 | 时长 | 音量 |
|------|--------|------|----------|------|------|
| `ui` 按钮点击 | 全部按钮/菜单切换 | square | 660→990 | 0.07s | 0.12 |
| `shoot` 玩家射击 | 自动开火每 0.16s | square | 940→320 | 0.06s | 0.05（节流 70ms） |
| `ehit` 敌机命中（非致命） | 精英敌机 `hitFlash` | square | 300→540 | 0.08s | 0.14 |
| `edie` 敌机击毁 | `e.dead` | square+noise | 430→60 | 0.22s | 0.2 / 0.16 |
| `phit` 玩家受击 | `hitPlayer()` | sawtooth+noise | 230→55 | 0.32s | 0.28 / 0.2 |
| `bhit` Boss 受击 | 子弹命中 Boss | square | 190→270 | 0.07s | 0.14 |
| `boss` Boss 出场 | `spawnBoss()` | sawtooth+square+noise | 55→120 / 120→240 | 0.9s | 0.22 / 0.1 |
| `charge` 激光蓄力 | P3 激光 `state=charge` | sawtooth | 180→720 | 1.1s | 0.12（与 1.2s 蓄力同步） |

| `gameover` 游戏结束 | `gameOver()` | square 下行三音 | 440→330→220 | 0.86s | 0.2 |

### 8.3 实现要点

- `tone(type, f0, f1, dur, vol, delay)`：振荡器 + 指数包络（5ms 起音，指数衰减到 0.0001），频率用 `exponentialRamp` 扫动。
- `noiseBurst(dur, vol, cutoff, delay)`：白噪声 Buffer + 线性衰减 + 低通滤波，用于爆炸/轰鸣质感。
- `sfx(name, arg)`：统一分发入口，`sfxOn=false` 直接短路；`shoot` 走 `performance.now()` 节流。
- 浏览器自动播放策略：`AudioContext` 在首个按钮点击时创建/恢复（`ensureAudio()`），此后全流程可发声。

### 8.4 BGM（8-bit 琶音循环）

- **构成**：128 BPM，`Am → F → C → G` 和弦进行（每和弦一小节，4 小节循环），三轨合成：
  - 琶音：三角波，和弦音 `[根音, 三音, 五音, 三音]` 每 8 分音符循环（音量 0.05）；
  - 贝斯：方波，每小节第 1/5 个 8 分音符播根音低八度（0.06）；
  - 踩镲：噪声短爆（0.03s，低通 6kHz，音量 0.02），奇数步增强节奏。
- **调度**：Lookahead 模式——`setInterval(25ms)` + 提前 120ms 按绝对时间排音符，节拍精确且无卡顿；生命周期：开始/继续 → `bgmStart()`，暂停/结束/回菜单 → `bgmStop()`。
- **静音联动**：`M` 键切换 `sfxOn` 时 BGM 一并启停；解除静音且处于游玩中时自动恢复。
- **性能**：全部实时合成、无限循环、零文件体积，与 SFX 共用单 AudioContext。
