# 零食金币狂飙赛 · UI 设计系统

> 参考来源：用户提供的手机录屏（`20260813-170313.mp4`）——微信小程序「9月零食金币狂飙赛」。
> 设计目标：把零食/糖果世界的可爱卡通赛车跑酷，复刻成零外部资源、单文件 HTML 可玩的版本。

---

## 1. 视觉定位

- **风格**：明亮、可爱、卡通、糖果世界
- **情绪**：轻快、放松、节日感（彩旗、蛋糕屋、糖果树）
- **表现手法**：Canvas 矢量绘制 + 圆角几何图形，避免真实图片，保持单文件零依赖
- **视角**：竖屏固定 3 车道俯视/后视，道路向屏幕下方滚动

---

## 3. 字体与排版

- **主字体**：系统圆角字体栈 `ui-rounded, "PingFang SC", "Microsoft YaHei", sans-serif`
- **数字**：使用系统默认无衬线，粗体，大字号
- **字号**
  - 标题：`clamp(28px, 7vw, 44px)` 加粗 900
  - 分数 HUD：`28px`
  - 按钮文字：`20px` 加粗 800
  - 说明文字：`14-16px`
  - 静音提示：`12px`

---

## 4. 布局与比例

- **逻辑画布**：540 × 1200（9:16 竖屏）
- **实际显示**：`width: min(100vw, 56.25vh); height: min(177.78vw, 100vh);` 保持比例居中
- **道路**：宽 360px，居中；3 条车道，每条 120px
- **玩家赛车**：固定位于画面下方约 920px 处
- **HUD**：顶部绝对定位，左右分离
  - 左侧：倒计时（圆形胶囊）
  - 中上：分数（大数字卡片）
- **控制区**：底部 18px，左右两个 72px 圆形按钮
- **安全边距**：道路两侧草地 90px，用于装饰性蛋糕屋/树木

## 5. 游戏元素规范

### 5.1 玩家赛车
- 黄色车身，红色保险杠，黑色车轮
- 车顶露出白色兔子头 + 长耳朵
- 半径约 40px 的碰撞圆
- 换道时做平滑插值动画（ease-in-out），耗时约 0.1s

### 5.2 金币
- 金色圆形，直径 32px
- 带 `¥` 符号（呼应录屏中金币样式）
- 轻微左右摆动（`wobble`）增加活泼感

### 5.3 交通锥
- 红底白条纹三角锥
- 底部阴影椭圆
- 碰撞即游戏结束（或触发护盾/复活）

### 5.4 闪电油桶道具
- 蓝色方形油桶，顶部深色盖子
- 黄色闪电符号
- 拾取后 5 秒加速 + 无敌

### 5.5 背景
- 天空：上蓝下浅的线性渐变
- 太阳：右上角暖黄圆形 + 外发光
- 远山：两层蓝色剪影，制造景深感
- 云朵：白色蓬松图形，缓慢横向飘动
- 近景：草地 + 蛋糕屋/糖果树随机生成并向下滚动

## 6. UI 组件

## 7. 动效与反馈

- **换道**：0.1s ease 插值 + 音效
- **收集金币**：粒子爆发（8 粒金色）+ `+10` 飘字
- **拾取道具**：12 粒蓝色粒子 + 「加速无敌！」飘字 + 赛车被护盾气泡包裹
- **撞击**：12 粒红色/白色粒子 + 屏幕震动感（通过粒子扩散表现）
- **加速状态**：赛车两侧白色速度线 + 道路滚动加快
- **护盾/无敌**：半透明气泡脉冲呼吸效果
- **Toast**：顶部淡入淡出，用于状态提示

---

## 8. 音效设计

全部使用 Web Audio API 程序化合成，零外部音频文件。

- **金币**：两个正弦波上行音（880Hz → 1175Hz）
- **道具**：锯齿波三音上行
- **撞击**：白噪声 + 低频方波下滑
- **换道**：短促 440Hz 正弦
- **结束**：锯齿波两音下行
- **复活**：三音上行正弦
- **BGM**：约 107 BPM，贝斯根音 + 方波琶音 + 噪声镲片，循环 4 和弦（C-G-Am-F）

---

## 9. 可访问性

- 所有覆盖层按钮支持键盘焦点与回车触发
- 控制同时支持键盘方向键、A/D、触屏按钮、滑屏
- 尊重 `prefers-reduced-motion`：在 hub 索引中已设置全局动效降级
- 文本对比度 ≥ 4.5:1
- 触摸目标 ≥ 44px（底部按钮 72px）
