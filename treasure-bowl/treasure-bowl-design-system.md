# 聚宝盆 · Treasure Bowl — UI 设计系统

> 合集第四款游戏。竖屏休闲接物：拖动聚宝盆接住天上掉落的元宝铜钱，避开炸弹。60 秒限时挑战最高分。

## 设计基调

**中国喜庆财气风（红金）**。与合集前三款——像素珊瑚战机、暖墨热气球、糖果赛车——形成鲜明主题区隔，但**交互范式保持一致**：竖屏优先、毛玻璃/木牌 HUD、菜单 overlay、M 键静音、Web Audio 程序化音效。

**约束**：所有 Canvas 绘制必须使用字面量十六进制，**禁止 `var(--…)`**——Canvas 上下文不识别 CSS 自定义属性，会抛 `SyntaxError` 导致首帧崩溃（见前车之鉴）。

## 元素精灵（Canvas 矢量绘制）

全部以逻辑坐标 `W=540, H=960` 绘制，DPR 缩放。

- **聚宝盆 bowl**（`drawBowl`）
  - 金渐变梯形：上宽 `topW=128`、下宽 `botW=84`、高 `h=58`
  - 椭圆盆口亮边 + 内凹暗面（暗示盆内空间）
  - 盆身祥云弧纹 + 回纹底座
  - 接住/无敌时 `globalAlpha` 脉动闪烁（视觉反馈）
- **金元宝 ingot**（`drawIngot`）：底盘椭圆 + 双翅尖上扬 + 鼓顶 + 白色高光，经典元宝造型
- **大元宝 big**（`drawBig`）：`ingot ×1.5` + 金色光环 + ★，标识 +50
- **铜钱 coin**（`drawCoin`）：外圆内方孔，铜金 `#c9a24a` / `#8a6d1f`
- **福袋 fu**（`drawFu`）：红袋 + 金绳 + 金「福」字，接到 +1 命
- **炸弹 bomb**（`drawBomb`）：黑球 + 棕色引线 + 随机火花（橙/金），危险语义明确

**帧动画（矢量形变，与 ① 同思路）**：① 聚宝盆整体随正弦轻微摇摆（±0.04rad），似被气流托浮；② 金元宝下落时绕中心摇摆旋转（±0.15rad）；③ 铜钱以 `scale(cos,1)` 做翻转（最小 0.15，模拟立起边缘）；④ 福袋左右轻摆（±0.1rad）；⑤ 炸弹背后叠加脉冲红光（±0.20 透明度，~8Hz）。全部由 `performance.now()` 驱动，无需额外位图资源。

## HUD

顶栏三块「木牌」（米白金边渐变 + 圆角 + 投影）：
- **分数**：竖排大数字（左上）
- **时间**：`⏱ Ns`（中）
- **生命**：`❤ N`（右）

右上角 44px **暂停键**（play 态显示），底部 `M 静音 · P 暂停` 提示。

## 玩法与反馈

- **控制**：拖动聚宝盆（pointer + setPointerCapture，逻辑坐标换算）+ 键盘 `←→`/`AD` + 暂停键；`M` 静音、`P` 暂停、`空格` 开始
- **收集反馈**：粒子爆发 + 飘字（`+10` / `+50` / `+5` / `+1命`）
- **炸弹反馈**：红色粒子爆 + toast「小心炸弹！」+ 1 秒无敌闪烁（盆变半透明）
- **生命**：初始 3，接炸弹 -1，归零结束；60 秒倒计时到亦结束
- **难度曲线**（随 elapsed 提升）：
  - 下落速度 `fallSpeed`：240 → 520 px/s
  - 生成间隔 `spawnInterval`：760 → 420 ms
  - 炸弹概率 `bombChance`：13% → 30%
- **物品权重**：金元宝（主）、铜钱、大元宝（稀有 +50）、福袋（稀有 +1 命）、炸弹
- **持久化**：最高分存 `localStorage['treasureBowlBest']`

## 音频（Web Audio 程序化，零文件）

- **SFX**：接元宝「叮」、大宝「铛」、铜钱、福袋、炸弹「爆」、结束
- **BGM**：五声音阶（C D E G A）`triangle` 贝斯 + `square` 琶音 + 噪声 hi-hat，约 100 BPM 喜庆循环
- **M 键**联动静音（音效 + BGM 同步）

## 可访问性

- 触控目标 ≥ 44px（暂停键、菜单按钮）
- `prefers-reduced-motion` 关闭过渡动画
- 颜色对比满足 WCAG AA（金/红文字 on 米白面板）
- 键盘可达：方向键移动、空格开始、M/P 功能键
