## 一、美学方向（Design Direction）

**去色世界 × 一抹带电的彩（Desaturated World, Electrified Color）**

核心视觉钩子来自玩法：**热气球起初是黑白的，吃到彩色闪电后才"上色"并短暂无敌**。据此把世界做成低饱和天空，让彩色元素（闪电 / 宝石 / 道具）成为唯一的色彩爆发点——天然形成"收集即点亮"的反馈语言，也避免"AI 网红配色"。

- **低饱和天空**做背景分层（非纯色），托住黑白气球。
- **黑白气球**作主角记忆点：浅灰体量 + 深灰描边，受击/平常都冷静。
- **彩色闪电方块**是唯一"通电"信号——吃到后气球染上该方块色 + 发光无敌，是世界里最跳的颜色。
- **宝石 / 道具**用克制的高饱和点色，零星点缀。
- 硬边像素、轻微视差云、指数缓动——和飞机大战同套"现代复古"质感，但更轻盈。

**差异化记忆点**：黑白气球 + 通电染色 + 钢灰栅栏，对比语言是"素 / 彩"。

## 二、设计基础 Tokens

### 2.1 调色板（受限，约 16 色）

```css
:root {
  /* ── 天空背景（低饱和，分层纵深）── */
  --sky-top:  #243a5e;  /* 顶部深蓝 */
  --sky-mid:  #3a5680;  /* 中层 */
  --sky-bot:  #5a78a0;  /* 底部雾霾蓝 */
  --cloud:    #6f8cb0;  /* 视差云（半透明） */

  /* ── 主角热气球：黑白（B/W）── */
  --bw-light: #e8ecf2;  /* 体量浅灰 */
  --bw-mid:   #9aa3b2;  /* 体量中灰（gore 暗条） */
  --bw-out:   #15181f;  /* 描边/绳索深黑 */
  --basket:   #7a4a2a;  /* 吊篮棕（固定色） */

  /* ── 通电染色（吃闪电后短暂覆盖 --bw-light/--bw-mid）── */

  --pu-slow:    #b56bff;  /* 缓降 · 紫 */
  --pu-magnet:  #ff8a3d;  /* 吸铁 · 橙 */
  --pu-double:  #ffd23f;  /* 双倍 · 金 */

  --panel:     #1b150e;  /* 面板底 */
  --panel-2:   #241c12;  /* 卡片/次面板 */
  --line:      #3a2f20;  /* 硬描边/分隔 */
  --ink:       #f3ead8;  /* 主文本 暖白 */

  --accent-deep:#b9882a; /* 金描边 */
  --live:      #3fd9c9;  /* 通电青 激活态强调 */

```

**对比度校验（WCAG AA）**：`--ink #f3ead8` on `--paper #100c08` ≈ **13.5:1**（≥4.5:1）；`--accent #ffcf4d` 通电金 on 深底 ≈ **10.8:1**；`--live #3fd9c9` 通电青 on 深底 ≈ **8.9:1**；栅栏/宝石为图形元素，非文本对比满足 3:1。

**UI 设计语言（外壳 / 菜单 / HUD / overlay）**：UI 默认单色暖墨（`--ink`/`--line`/`--panel`），彩色仅作「通电」语义强调——`--accent` 通电金用于标题、分数、主按钮；`--live` 通电青用于激活态/生命/通电反馈。与玩法「气球初始黑白、吃闪电才上色」同一套语言，界面即玩法预告。面板/按钮均 `2px` 硬描边 + `0 2px 0` 硬阴影偏移（按下 `inset`），无圆角、无 `backdrop-filter` 模糊，保持街机质感与性能。HUD 用「小标签（微字 11px）+ 大数字（`--accent` 带 2px 像素阴影）」结构分组；过渡统一 `cubic-bezier(.22,1,.36,1)`，尊重 `prefers-reduced-motion`。

### 2.2 字体系统（与合集一致）

```css
--font-display: 'Press Start 2P', 'Courier New', monospace;  /* 标题 / 分数 / 按钮 */

```

| 角色 | 字号（逻辑 px） | 行高 | 用途 |
|------|----------|------|------|
| 巨型标题 | 14（展示体） | 1.4 | LOGO / GAME OVER |
| 分数数字 | 16（等宽） | 1 | HUD 实时分数 |
| 按钮 | 10（展示体） | 1 | 主操作 |
| 正文/说明 | 16（等宽） | 1.2 | 说明、提示 |

> 同飞机大战：像素展示体仅用于标题/分数/按钮，正文用高可读 VT323；Google Fonts 离线回退 `monospace`。

### 2.3 间距系统（4px 网格，像素对齐）

```
--space-1: 4px  --space-2: 8px  --space-3: 12px
--space-4: 16px --space-6: 24px --space-8: 32px --space-12: 48px
```

### 2.4 动效规范

- **缓动**：`cubic-bezier(0.16, 1, 0.3, 1)`（ease-out-expo），禁用回弹。
- **通电染色**：吃闪电后气球染 hue + 外发光脉冲 0.5s 渐入；无敌期间 60ms 周期透明度闪烁。
- **栅栏命中**：无敌时栅栏碎裂为钢灰方块粒子（0.4s）；非无敌则 Game Over（红闪 + 轻震）。
- **云视差**：2 层云，向下滚动，速度随难度微增。
- **尊重 `prefers-reduced-motion`**：关闭闪烁与震动，保留核心反馈。

## 三、组件库（UI Components）

> 界面用 DOM 覆盖在 Canvas 之上（文本清晰 + 可访问性），风格统一：像素描边 + 半透明面板 + 展示体标题。

### 3.1 主菜单（Main Menu）
- 居中面板 `--panel`，`--border` 2px 像素描边 + 硬阴影。
- LOGO：展示体巨型标题「热气球大冒险」，冰蓝填充 + 深描边。
- 一行机制说明（内联提示）：「← → / 拖动 左右移动 · 吃闪电变色无敌 · 吃宝石得分」。
- 主按钮「开始游戏」`--ui-accent` 底、`--bg-void` 字（复用合集按钮规范）。

### 3.2 HUD（游戏内）
- 顶部左右：**SCORE**（零填充 6 位）｜**BEST**（localStorage）。
- 右上角暂停按钮（≥44px 触控）。
- **等级条**（level-bar）：score 下方一条 `LV N + 进度条`，进度 = `score%200 / 200`，随分数实时填充，升级瞬间回零。仅 PLAY 状态显示。
- 效果条（effects）：下方一排小芯片，显示当前生效能力 + 剩余秒数——**通电染色**（方块色块）、**护盾**（冰蓝）、**缓降**（紫）、**吸铁**（橙）、**双倍**（金）。每个芯片含 1px 像素描边 + 剩余时间条。
- **飘字**（Canvas 内）：吃宝石 `+10/+20`、险胜 `险 +5`、通电 `通电!`、道具名，向上浮升 0.9s 淡出，正反馈即时可读。
- **染色闪光**（flash 层）：吃到闪电瞬间全屏 0.45→0 闪一下该 hue，强化"通电"爽感。
- 顶部细扫描线渐变，强化街机感。

### 3.3 暂停（Pause）
- 半透明遮罩（alpha 0.7）+ 居中面板。「已暂停」+「继续 / 重新开始 / 退出」。
- 触发：桌面 `P` / `Esc`；移动端点暂停按钮。

### 3.4 游戏结束（Game Over）
- 展示体「GAME OVER」`--ui-danger`。
- 本局分数 + 最高分。
- 「再来一局」主按钮 +「返回菜单」。

### 3.5 按钮规范（与合集一致）

## 四、像素精灵规范（Sprite Spec）

> 渲染方式：Canvas 逻辑分辨率 **270×480**（9:16），CSS `image-rendering: pixelated` 放大；精灵以字符矩阵定义，`drawSprite(matrix, palette, x, y)` 渲染，`SPRITE_SCALE=1`（1:1 像素，无整数放大糊化）。全部 ≤ 32×32，符合 `sprite-rules.md` R1，无需预渲染。

### 4.1 热气球（24×28，程序化生成 `buildBalloon()`）
- **造型**：上半椭圆气囊（gore 竖条 `T`/`S` 交替，模拟热气球分瓣）+ 深黑描边 `O` + 底部绳索 `R` + 吊篮 `B`（固定棕）。
- **染色机制**：矩阵只定义结构通道 `O/T/S/B/R`；绘制时按状态注入调色板——

  | 状态 | `T`（体量） | `S`（暗瓣） |
  |------|-----------|-----------|
  | 初始 / 非无敌 | `--bw-light #e8ecf2` | `--bw-mid #9aa3b2` |
  | 通电染色（无敌） | 闪电 hue（青/品红/金/绿） | `shade(hue)` 压暗 |

- 这样**一份矩阵支持黑白↔彩色无缝切换**，无需维护两套图。
- 碰撞框 22×26（内缩描边），位置 `y = 480 - 64`（距底约 64px 操作余量）。

### 4.2 栅栏障碍（钢灰方块，`fillRect` 直绘，非矩阵）
- 每波一行一个：长度 `L = 45 + rand*85`（≤ 135 = 屏宽一半），右移保证余隙 ≥ 半屏，必可通过。
- 渲染：主体 `--fence` 钢灰 + 顶 2px `--fence-warn` 红警示 + `--fence-dark` 描边 + 底部铆钉点（每 8px 一个），制造"金属挡板"识别。
- 碰撞：AABB；无敌时碎裂粒子，否则 Game Over。
- **险胜（near miss）**：纵向重叠但水平缝隙 < 10px 时 +5 分 + `险 +5` 飘字（每根栅栏仅触发一次），奖励"擦边"操作。

### 4.3 宝石（9×9 手绘矩阵，计分）
- 菱形，`G`=宝石色（青/金/珊瑚轮换）、`W`=白色高光。吃一颗 `+10`（金 `+20`）。
- 在栅栏外的剩余空间随机生成，随波下落。

### 4.4 彩色闪电方块（11×11 手绘矩阵，签名机制）
- 圆角方块 `B`=闪电色（同 hue 池）+ `O` 描边 + `L` 白色闪电纹。
- 吃后：气球染该 hue + 进入无敌（默认 4s）。出现概率 ~6%/波。

### 4.5 道具（11×11 圆盘矩阵 `buildPowerup()`，四类）
- 圆盘 `B`=道具色 + `O` 描边，按类型换色区分；HUD 用文字标签补足辨识。
- 四类能力（默认提案，可调）：

  | 道具 | 色 | 效果 |
  |------|----|------|
  | 护盾 shield | 冰蓝 | 无敌 5s（蓝色护盾环，不染色） |
  | 缓降 slow | 紫 | 下落速度 ×0.5，5s |
  | 吸铁 magnet | 橙 | 宝石向气球吸附，6s |
  | 双倍 double | 金 | 计分 ×2，8s |

- 出现概率 ~8%/波；与闪电/宝石在空间上错开。

### 4.6 背景
- 天空竖向渐变（top→bot）+ **三层视差**：远云（最慢最淡）→ 近云（中速）→ 远山轮廓（底部两层折线，浅/深叠层），营造高空下落纵深感。
- 收集物（宝石/闪电/道具）轻微上下浮动（`sin(elapsed*4 + x*0.1)` ±1px），避免静止呆板。

## 五、响应式与平台

- **竖屏优先**（9:16），`game-shell` `aspect-ratio: 270/480`，`min(100vw, 100vh*270/480)` 居中。
- **输入双通道**（与合集一致）：
  - 桌面：方向键 / `A`·`D` 左右移动（按住连续），`P`/`Esc` 暂停。
  - 移动：手指拖动 → 气球 x 跟随指下横向位置（pointer 事件，夹紧边界）。
- 不做"移动端隐藏功能"——两端核心操作等价。

## 七、实现备注（Developer Handoff）

1. Canvas 固定 `width=270 height=480`（属性像素），CSS 放大 + `image-rendering: pixelated`。
2. 主循环 `requestAnimationFrame` + 可变步长（`dt` 钳制 0.05s）。
3. UI 层独立 DOM 覆盖，`pointer-events` 仅菜单/按钮启用，避免遮挡触控移动。
4. 最高分 `localStorage('hotAirBalloon.best')`。
5. 精灵：`buildBalloon()` / `buildGem` 静态 / `buildBolt` 静态 / `buildPowerup()`，统一 `drawSprite(matrix, palette, x, y)`。
6. 难度由分数驱动（曲线重调）：`level = min(12, floor(score/200))`；下落速度 `60 + level*12`（封顶 ~204），生成间隔 `max(0.72, 1.4 - level*0.057)`；闪电概率 `5%→9%`、道具概率 `9%→5%`（均随 level 线性变化，后期更紧张但救命稻草增多）。
7. 碰撞：气球 AABB vs 栅栏/宝石/闪电/道具；无敌（`inv>0`）时穿过栅栏并碎裂。**险胜**：纵向重叠但水平缝隙 < 10px → +5 分 + 飘字（每根栅栏一次）。
8. 手感：拖拽绝对跟随（阻尼 `dt*13`）；键盘**惯性**（加速 1500 + 强摩擦 `pow(0.0008,dt)` + 速度钳制）；气球**倾斜**（`tilt` 跟随 `vx`，lerp 平滑，±0.13rad）+ 待机摆动；边界**软回弹**（撞墙 `vx*-0.3`）；高速时生成拖尾气流粒子。
9. 反馈层：`burst()` 粒子爆发（吃宝石/闪电/道具）、`pushFloat()` 飘字、`triggerFlash()` 染色全屏闪光；粒子带 `max` 寿命归一 alpha、`sz` 控制大小（拖尾 1px / 爆发 2px）。
